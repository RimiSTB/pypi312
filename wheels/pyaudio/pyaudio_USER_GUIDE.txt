================================================================================
  1. OVERVIEW
================================================================================

PyAudio provides Python bindings for PortAudio, the cross-platform audio
I/O library. This build statically links PortAudio with the Android
OpenSLES backend for native audio support on Android STB devices.

================================================================================
  4. USAGE EXAMPLE
================================================================================

    import pyaudio

    p = pyaudio.PyAudio()
    stream = p.open(format=pyaudio.paInt16,
                    channels=1,
                    rate=44100,
                    output=True)
    data = b"\x00\x00" * 44100  # 1 second silence
    stream.write(data)
    stream.close()
    p.terminate()
