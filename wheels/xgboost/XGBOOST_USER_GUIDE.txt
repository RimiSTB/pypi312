3. QUICK START
================================================================================

  import numpy as np
  import xgboost as xgb

  # Create sample data
  X = np.random.rand(1000, 10).astype(np.float32)
  y = (X[:, 0] + X[:, 1] * 2 + np.random.randn(1000) * 0.1).astype(np.float32)

  # Create DMatrix
  dtrain = xgb.DMatrix(X, label=y)

  # Set parameters
  params = {
      'max_depth': 6,
      'eta': 0.1,
      'objective': 'reg:squarederror',
      'eval_metric': 'rmse',
  }

  # Train
  model = xgb.train(params, dtrain, num_boost_round=100)

  # Predict
  X_test = np.random.rand(100, 10).astype(np.float32)
  dtest = xgb.DMatrix(X_test)
  predictions = model.predict(dtest)

  # Save/Load model
  model.save_model('model.json')
  model2 = xgb.Booster()
  model2.load_model('model.json')

  # Sklearn API
  from xgboost import XGBRegressor, XGBClassifier
  model = XGBRegressor(n_estimators=100, max_depth=6)
  model.fit(X, y)
  preds = model.predict(X_test)

4. API REFERENCE
================================================================================

  CORE:
    xgb.DMatrix(data, label=None, ...)  - Data container for XGBoost
    xgb.train(params, dtrain, ...)      - Train a model
    xgb.Booster()                       - Model object
    xgb.cv(params, dtrain, ...)         - Cross-validation

  DMATRIX:
    DMatrix.num_row()     - Number of rows
    DMatrix.num_col()     - Number of columns
    DMatrix.save_binary() - Save to binary format
    DMatrix.get_label()   - Get labels

  BOOSTER:
    booster.predict(data)           - Make predictions
    booster.predict(data, pred_leaf=True)  - Get leaf indices
    booster.save_model(path)        - Save model (JSON or binary)
    booster.load_model(path)        - Load model
    booster.get_score()             - Feature importance
    booster.get_dump()              - Get tree dump
    booster.set_param(params)       - Set parameters

  SKLEARN API:
    XGBRegressor(...)
    XGBClassifier(...)
    XGBRFRegressor(...)
    XGBRFClassifier(...)

  OBJECTIVES (regression):
    reg:squarederror      - Mean squared error

  OBJECTIVES (classification):
    binary:logistic       - Binary logistic regression

5. DEVICE USAGE TIPS
================================================================================

  MEMORY:
    - XGBoost uses memory-efficient histogram-based training
    - For large datasets, use external memory: xgb.DMatrix('file.txt?format=csv')
    - DMatrix is much more memory efficient than numpy arrays
    - For STB, keep datasets under 1M rows to avoid OOM

  PERFORMANCE:
    - XGBoost is highly optimized for ARM NEON
    - Use tree_method='hist' (default) for speed
    - max_depth=6 is a good default; deeper trees are slower
    - num_boost_round=100-500 is usually sufficient
    - Use early_stopping_rounds to prevent overfitting

  TRAINING TIPS:
    - Set verbosity=0 to reduce output on STB
    - Use eval_metric that matches your problem
    - For imbalanced classes, use scale_pos_weight
    - Use early_stopping with eval_set for best iteration

  MODEL SIZE:
    - JSON models are larger but human-readable
    - Binary models are smaller and faster to load
    - For deployment, use binary format

  COMPATIBLE WITH:
    - numpy (required)
    - scipy (required)
    - scikit-learn (via XGBClassifier/XGBRegressor)
    - pandas (via narwhals)
    - matplotlib (for visualization, if available)

  WORKAROUNDS:
    - No GPU support on Android (CPU only)
    - No distributed training on single STB
    - Use tree_method='hist' (histogram-based) for CPU
    - For very large datasets, consider external memory

  ERROR: ImportError with __ndk1 ABI
    -> This was the original Android build issue
    -> The wheel must be rebuilt with proper NDK ABI flags
    -> Ensure CMake cross-compile uses -DANDROID_ABI=arm64_v8a

  ERROR: "undefined symbol: __ndk1"
    -> C++ ABI mismatch between wheel and runtime
    -> Rebuild with matching NDK version and ABI settings

  ERROR: "libxgboost.so not found"
    -> XGBoost should be statically linked into _xgboost.so
    -> Rebuild with -DGOOGLE_TEST=OFF and static linking

  SLOW TRAINING:
    - Use tree_method='hist' (default, fastest)
    - Reduce max_depth (3-6 is good for STB)
    - Reduce num_boost_round (100-200)
    - Use subsample and colsample_bytree for speed

  MEMORY ISSUES:
    - Use external memory for large datasets
    - Reduce max_bin parameter
    - Use float32 instead of float64
    - Enable early_stopping to limit model size

  MODEL LOADING ERRORS:
    - Ensure model was saved with compatible version
    - Use JSON format for portability
    - Check file is not corrupted

  STORAGE:
    - Wheel: ~15-20 MB
    - Installed: ~20-25 MB
    - Model files: ~1-100 KB typical
