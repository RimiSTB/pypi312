  1. OVERVIEW
================================================================================

psycopg2 is the most popular PostgreSQL adapter for Python. This build
statically links libpq to provide a self-contained wheel for Android STB
environments without requiring system PostgreSQL libraries.

================================================================================

================================================================================

    pip install /path/to/psycopg2-*.whl

Or from within a build environment:

    python -m pip install --no-build-isolation psycopg2

================================================================================
  5. TROUBLESHOOTING
================================================================================

  - If import fails with "cannot find shared library" the wheel was not
    built with a static linking strategy. Rebuild with the correct
    build script.
  - Ensure your Android Python STB environment matches the ABI that
    the wheel was compiled for (typically arm64_v8a / aarch64).
  - Static libpq must have SSL support compiled in if connecting to
    SSL-enabled PostgreSQL servers.
