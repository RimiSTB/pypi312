1. OVERVIEW
================================================================================

scikit-image (skimage) is a collection of algorithms for image processing.
Built for Android Python STB with Cython extensions compiled via meson.

Version:    0.24.x (latest 0.x series)
Modules:    38 submodules compiled into wheel
Extensions: Cython (.so) compiled with norelro + 16KB page alignment
Deps:       numpy (required), scipy (optional), lazy_loader, tifffile
Size:       ~25-35 MB wheel (all extensions)

3. QUICK START
================================================================================

  # Read a built-in image
  from skimage import data
  img = data.camera()          # 512x512 grayscale
  img = data.astronaut()       # 512x512x3 color

  # Apply Gaussian filter
  from skimage.filters import gaussian
  smoothed = gaussian(img, sigma=1.0)

  # Threshold
  from skimage.filters import threshold_otsu
  thresh = threshold_otsu(img)
  binary = img > thresh

  # Edge detection
  from skimage.feature import canny
  edges = canny(img)

  # Label connected components
  from skimage.measure import label
  labels = label(binary)

  # Region properties
  from skimage.measure import regionprops
  props = regionprops(labels)
  for p in props:
      print(p.area, p.bbox)

5. DEVICE USAGE TIPS
================================================================================

  MEMORY:
    - Image operations are memory-intensive; process images in tiles if needed
    - For 1080p images (~6MB RAM each), limit concurrent operations
    - Use float32 instead of float64 to halve memory usage

  PERFORMANCE:
    - Prefer numpy operations where possible (faster on ARM)
    - Use num_threads parameter in multi-threaded functions
    - Gaussian filter with sigma > 5 is slow; use pyramid reduction first

  WORKAROUNDS:
    - skimage.io may not work without Pillow; use cv2 or PIL directly
    - Some functions require scipy; install it if you get ImportErrors
    - plotly/matplotlib visualization is not available on STB

  COMPATIBLE WITH:
    - OpenCV (cv2) for additional I/O and processing
    - Pillow (PIL) for image loading
    - numpy for array manipulation

    - Avoid repeated imports; import once and reuse

  STORAGE:

    - Temp files from some operations: clean up periodically
