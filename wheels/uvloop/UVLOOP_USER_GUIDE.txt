1. OVERVIEW
================================================================================

uvloop is a fast, drop-in replacement for asyncio's event loop.
Built on top of libuv (the same library powering Node.js).

Version:        0.21.x / 0.22.x
Extensions:     1 compiled C extension (loop.cpython-312-*.so)
Libuv:          Statically linked (libuv.a)
Wheel Size:     ~1-2 MB
Dependencies:   None (standalone)
Performance:    2-4x faster than asyncio default loop

================================================================================
2. INSTALLATION
================================================================================

  pip install uvloop-<version>-cp312-cp312-linux_aarch64.whl

No dependencies required.

After install, verify:
  python -c "import uvloop; print(uvloop.__version__)"

3. QUICK START
================================================================================

  # Method 1: Install uvloop as default event loop
  import uvloop
  uvloop.install()

  import asyncio

  async def main():
      print("Hello from uvloop!")
      await asyncio.sleep(1)
      print("Done!")

  asyncio.run(main())

  # Method 2: Create uvloop event loop directly
  import uvloop
  import asyncio

  loop = uvloop.new_event_loop()
  asyncio.set_event_loop(loop)

  async def main():
      await asyncio.sleep(1)

  loop.run_until_complete(main())
  loop.close()

  # Method 3: Use as drop-in replacement
  import uvloop
  import asyncio

  # This makes uvloop the default for all asyncio code
  uvloop.install()

  # Now all asyncio operations use uvloop
  asyncio.run(your_existing_async_code())

4. API REFERENCE
================================================================================

  uvloop.install()
    Installs uvloop's event loop policy as the default.
    All subsequent asyncio.new_event_loop() calls return uvloop.
    This is the recommended way to use uvloop.

  uvloop.new_event_loop()
    Creates a new uvloop event loop instance.
    The loop is not set as the current event loop.
    You must call asyncio.set_event_loop(loop) to make it active.

  uvloop.EventLoopPolicy
    The event loop policy class for uvloop.
    Can be used with asyncio.set_event_loop_policy().

    import asyncio
    asyncio.set_event_loop_policy(uvloop.EventLoopPolicy())

  uvloop.__version__
    String containing the uvloop version number.

  uvloop.__uvloop__
    Boolean indicating this is the uvloop C extension.

5. DEVICE USAGE TIPS
================================================================================

  PERFORMANCE:
    - uvloop is 2-4x faster than asyncio default on ARM
    - libuv is optimized for I/O operations
    - Very efficient for high-concurrency network I/O
    - Use for Telegram bots, HTTP servers, WebSocket clients

  MEMORY:
    - Wheel is only ~1-2 MB
    - Event loop overhead is minimal (~100 KB)
    - Can handle thousands of concurrent connections

  BEST PRACTICES:
    - Always use uvloop.install() at program start
    - Don't create multiple event loops; reuse one
    - Use asyncio.gather() for concurrent tasks
    - Use asyncio.wait_for() for timeouts

  NETWORK I/O:
    - Excellent for TCP/UDP servers
    - Works great with aiohttp for HTTP servers
    - Supports DNS resolution via libuv
    - Handles large numbers of concurrent connections efficiently

  TELEGRAM BOTS:
    - Telethon works great with uvloop
    - python-telegram-bot works with uvloop
    - Highly recommended for bot applications

  WORKAROUNDS:
    - Some C extensions may not be compatible with uvloop
    - If you get "loop already running" errors, ensure single loop
    - For subprocess, use asyncio.create_subprocess_exec

  COMPATIBLE WITH:
    - aiohttp (web framework)

6. TROUBLESHOOTING
================================================================================

  ERROR: "No module named 'uvloop'"
    -> Install uvloop wheel: pip install uvloop-<ver>-cp312-cp312-linux_aarch64.whl

  ERROR: "loop.cpython-312-aarch64-linux-gnu.so not found"
    -> Wheel may not have been built for aarch64
    -> Check wheel contents: unzip -l uvloop-*.whl

  ERROR: "cannot allocate memory in static TLS block"
    -> Too many thread-local storage allocations
    -> Reduce number of concurrent libraries loaded
    -> This is rare on Android

  ERROR: "event loop is closed"
    -> Don't call loop.close() and then try to use it
    -> Create new loop or use asyncio.run() which manages lifecycle

  ERROR: "RuntimeError: Event loop is closed"
    -> Same as above - ensure loop lifecycle is managed correctly
    -> Use asyncio.run() for simple programs

  ERROR: "ImportError: libuv.so not found"
    -> This should not happen if uvloop was built with static libuv
    -> Rebuild uvloop with libuv statically linked

  ERROR: "RuntimeError: Event loop already running"
    -> Don't call loop.run_until_complete() inside running loop
    -> Use asyncio.create_task() instead

  PERFORMANCE ISSUES:
    - uvloop is fast but may not help if bottleneck is CPU-bound
    - For CPU-bound work, use multiprocessing
    - uvloop shines for I/O-bound applications

  COMPATIBILITY ISSUES:
    - Some asyncio features may behave slightly differently
    - Check uvloop docs for known differences
    - Test thoroughly before deploying

  STORAGE:
    - Wheel: ~1-2 MB
    - Installed: ~3-5 MB (including libuv.a)
    - Very lightweight
