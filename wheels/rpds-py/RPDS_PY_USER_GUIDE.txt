--------------------------------------------------------------------------------
1) WHAT IS RPDS-PY?
--------------------------------------------------------------------------------

rpds-py provides persistent (immutable) data structures for Python, implemented
in Rust via PyO3. Available data structures:
  - Map -- persistent sorted map (red-black tree)
  - List -- persistent vector (array-mapped trie)
  - Set -- persistent sorted set (red-black tree)
  - Stack -- persistent stack (linked list)
  - Queue -- persistent queue (banker's queue)

"Persistent" means every modification returns a NEW collection, leaving the
original unchanged. This enables safe sharing across functions/threads.

    from rpds import Map, List, Set
    m = Map()
    m2 = m.set("key", "value")
    print(len(m))    # 0  (original unchanged)
    print(len(m2))   # 1  (new version)

8) PERSISTENCE GUARANTEE
--------------------------------------------------------------------------------

All rpds data structures are immutable after creation:

    from rpds import Map

    original = Map()
    modified = original.set("key", "value")

    print(len(original))   # 0  -- unchanged
    print(len(modified))   # 1  -- new version

This makes them safe for concurrent access without locks.

--------------------------------------------------------------------------------
10) PITFALLS & NOTES
--------------------------------------------------------------------------------

- rpds data structures are IMMUTABLE. m["key"] = val returns a new object.
- Use .set(), .append(), .add(), .push(), .enqueue() for modifications.
- Each modification creates a new version (O(log n) for most operations).
- Old versions remain accessible (structural sharing).
- Do NOT use mutable operations expecting in-place changes.
- Map/Set iterate in sorted order (by key/value).
- List iteration is in insertion order.
- Stack is LIFO, Queue is FIFO.
- Wheels are tagged cp312-cp312-android_24.
- Built with Rust/PyO3 via maturin.
- No external runtime dependencies.
