5. DEVICE USAGE TIPS
================================================================================

  MEMORY:
    - scipy wheel is ~85-89 MB; ensure sufficient storage
    - Sparse matrices save memory for large systems
    - Use float32 for memory-constrained applications
    - linalg operations on large matrices (>1000x1000) may OOM

  PERFORMANCE:
    - f2c'd BLAS is ~2-5x slower than OpenBLAS on ARM
    - For matrix ops, prefer numpy where possible (faster for small matrices)
    - Sparse solvers are essential for large sparse systems
    - FFT operations are reasonable performance with pocketfft

  OPTIMIZATION:
    - Use 'Nelder-Mead' for derivative-free optimization
    - Use 'BFGS' for smooth functions with known gradients
    - 'differential_evolution' for global optimization (slower)

  WORKAROUNDS:
    - Some LAPACK routines may be unavailable in f2c'd version
    - Fortran-based ODE solvers may have issues; use Python implementations
    - scipy.io.matlab may not work with v5 .mat files

  COMPATIBLE WITH:
    - numpy (required)
    - scikit-learn (uses scipy.stats, scipy.sparse)
    - scikit-image (uses scipy.ndimage, scipy.optimize)
    - OpenCV (cv2) for image I/O
