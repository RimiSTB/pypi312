--------------------------------------------------------------------------------
1) WHAT IS AIOHTTP?
--------------------------------------------------------------------------------

aiohttp is an asynchronous HTTP client and server library for Python.
It provides:
  - Async HTTP client (GET, POST, PUT, DELETE, etc.) using asyncio
  - Async HTTP server with request routing and middleware
  - WebSocket client and server support
  - Connection pooling and keep-alive
  - Cookie handling and session management
  - Multipart form/file uploads
  - SSL/TLS support with custom certificates

aiohttp depends on: multidict, frozenlist, yarl, propcache, aiosignal, attrs.

    import aiohttp
    print(aiohttp.__version__)          # 3.12.x

3) BASIC USAGE - CLIENT
--------------------------------------------------------------------------------

    import aiohttp, asyncio

    async def fetch():
        async with aiohttp.ClientSession() as session:
            async with session.get("https://httpbin.org/get") as resp:
                print(resp.status)        # 200
                print(await resp.text())  # response body
                print(resp.headers)       # response headers

    asyncio.run(fetch())

    import aiohttp

    # default session
    session = aiohttp.ClientSession()

    # custom timeout
    timeout = aiohttp.ClientTimeout(total=30, connect=10, sock_read=15)
    session = aiohttp.ClientSession(timeout=timeout)

    # custom connector
    conn = aiohttp.TCPConnector(limit=100, limit_per_host=10, ttl_dns_cache=300)
    session = aiohttp.ClientSession(connector=conn)

    # always close when done
    await session.close()

    # or use async with (recommended)
    async with aiohttp.ClientSession() as session:
        pass

--------------------------------------------------------------------------------
12) ANDROID NOTES
--------------------------------------------------------------------------------

- aiohttp requires an event loop. On Android, use asyncio.run().
- Network access requires INTERNET permission in AndroidManifest.xml.
- SSL certificates may differ on Android; use ssl=False for testing if needed.
- aiohttp imports C extensions (_http_parser, _websocket, _speedups, _cookies)
  which must be compiled for the target ABI.
- For HTTP/2 support, consider curl_cffi instead.
- aiohttp is async-only; for synchronous requests, use requests or urllib3.
