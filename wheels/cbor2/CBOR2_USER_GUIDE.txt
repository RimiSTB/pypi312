--------------------------------------------------------------------------------
1) WHAT IS CBOR2?
--------------------------------------------------------------------------------

CBOR2 is a Python library for encoding and decoding CBOR (Concise Binary Object
Representation) data - an IETF standard (RFC 8949) binary serialization format.

CBOR is similar to JSON but:
  - Binary (smaller, faster to parse)
  - Supports more types: bytes, dates, tags, big integers, half-precision floats
  - Self-describing (type information is embedded)
  - Used in IoT, COSE, CWT, WebAuthn, and other protocols

cbor2 is self-contained (Rust/PyO3 build), no external dependencies.

    import cbor2
    print(cbor2.__version__)          # 5.x

--------------------------------------------------------------------------------
3) BASIC ENCODING / DECODING
--------------------------------------------------------------------------------

    import cbor2

    # encode (dumps) - returns bytes
    data = cbor2.dumps(42)
    data = cbor2.dumps("hello")
    data = cbor2.dumps([1, 2, 3])
    data = cbor2.dumps({"key": "value"})

    # decode (loads) - returns Python object
    obj = cbor2.loads(data)

    # encode to file (dump)
    with open("data.cbor", "wb") as f:
        cbor2.dump({"key": "value"}, f)

    # decode from file (load)
    with open("data.cbor", "rb") as f:
        obj = cbor2.load(f)


--------------------------------------------------------------------------------
4) SUPPORTED TYPES
--------------------------------------------------------------------------------

CBOR Type           -> Python Type
-------------------------------------------
unsigned int        -> int
negative int        -> int
byte string         -> bytes
text string         -> str
array               -> list
map                 -> dict
boolean             -> bool
null                -> None
float (double)      -> float
float (half)        -> float
undefined           -> cbor2.CBORTag or None

5) CBOR TAGS
--------------------------------------------------------------------------------

    import cbor2

    # standard tags
    tag = cbor2.CBORTag(1, "2026-01-15")   # standard date/time
    data = cbor2.dumps(tag)
    result = cbor2.loads(data)
    print(result.tag)     # 1
    print(result.value)   # "2026-01-15"

    # URL tag (32)
    tag = cbor2.CBORTag(32, "https://example.com")

    # base64url tag (21)
    tag = cbor2.CBORTag(21, "SGVsbG8=")

--------------------------------------------------------------------------------
9) ANDROID NOTES
--------------------------------------------------------------------------------

- cbor2 is self-contained; no external dependencies needed.
- The Rust/PyO3 build produces a single .so extension.
- Works fully offline (no network needed).
- Thread-safe for encoding/decoding.
- CBOR data is compact; good for limited storage/bandwidth.
- Use cbor2.dumps() + cbor2.loads() for in-memory operations.
- Use cbor2.dump() + cbor2.load() for file I/O.
