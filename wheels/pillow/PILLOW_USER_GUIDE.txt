## What is pillow
  Python Imaging Library (Pillow) — image processing library.
  Supports JPEG, PNG, TIFF, WebP, BMP, GIF, ICO, and many more formats.

## Installation
  pip install pillow-12.3.0-cp312-cp312-android_24_x86_64.whl

  Or for arm64:
  pip install pillow-12.3.0-cp312-cp312-android_24_arm64_v8a.whl

## Features enabled
  ✓ JPEG/JPEG2000 (libjpeg-turbo 3.0.4, OpenJPEG 2.5.2)
  ✓ TIFF (libtiff 4.7.0)
  ✓ WebP (libwebp 1.4.0)
  ✓ FreeType (freetype 2.13.3) — font rendering
  ✓ LittleCMS 2.16 — ICC color management
  ✓ libimagequant 2.17.0 — high-quality quantization
  ✓ zlib — PNG compression

## Usage
  from PIL import Image, ImageFilter, ImageDraw, ImageFont

  # Open image
  img = Image.open("photo.jpg")

  # Resize
  img = img.resize((800, 600))

  # Save
  img.save("output.png")

## Dependencies
  pillow is standalone — no extra packages needed.

## Known limitations
  - webp_mux: False (WebP muxing not compiled in)
  - png feature check reports False but zlib support works
  - tkinter not available on Android (ImageTk skipped)
