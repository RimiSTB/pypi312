  1. OVERVIEW
================================================================================

argon2_cffi_bindings provides Python bindings for the award-winning Argon2
password hashing algorithm. It uses CFFI to interface with a statically
linked libargon2 library, making it ideal for Android STB environments
where shared libraries may not be available.
