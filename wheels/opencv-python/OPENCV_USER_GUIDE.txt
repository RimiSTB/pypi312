1) WHAT IS OPENCV-PYTHON?
--------------------------------------------------------------------------------

OpenCV (Open Source Computer Vision Library) provides:
  - Image and video I/O (read, write, encode, decode)
  - Color conversion (BGR, GRAY, HSV, RGB, ...)
  - Image processing (blur, threshold, edge detection, morphology)
  - Feature detection (corners, edges, templates)
  - Drawing and annotation
  - Contour analysis
  - Video capture and writing

This Android build includes: core, imgproc modules only (lightweight).

3) HOW __INIT__.PY LOADS .so FILES
--------------------------------------------------------------------------------

This Android build's __init__.py uses ctypes.CDLL to pre-load .so files in
dependency order before importing the cv2 module:

    import ctypes, os, sys

    # Add package dir to LD_LIBRARY_PATH
    _dir = os.path.dirname(os.path.abspath(__file__))
    _ld = os.environ.get("LD_LIBRARY_PATH", "")
    if _dir not in _ld.split(":"):
        os.environ["LD_LIBRARY_PATH"] = _dir + (":" + _ld if _ld else "")

    from .cv2 import *       # now cv2.so loads all symbols

The .so files in the cv2/ directory are loaded in this order:
  1. libopencv_core.so
  2. libopencv_imgproc.so
  3. cv2.cpython-312.so (Python bindings)

This is important because OpenCV modules depend on each other. The __init__.py
ensures the dependency chain is loaded correctly.

    import cv2
    import numpy as np

    img = np.zeros((200, 200), dtype=np.uint8)
    cv2.rectangle(img, (20, 20), (180, 180), 255, -1)

    contours, hierarchy = cv2.findContours(
        img, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE
    )

    for cnt in contours:
        area = cv2.contourArea(cnt)
        perimeter = cv2.arcLength(cnt, closed=True)
        x, y, w, h = cv2.boundingRect(cnt)
        print("area=%d perimeter=%d bbox=(%d,%d,%d,%d)" % (area, perimeter, x, y, w, h))

10) FEATURE DETECTION
--------------------------------------------------------------------------------

    import cv2
    import numpy as np

    # Good features to track (Shi-Tomasi corners)
    gray = np.zeros((200, 200), dtype=np.uint8)
    gray[95:105, 95:105] = 255
    corners = cv2.goodFeaturesToTrack(gray, maxCorners=10,
                                      qualityLevel=0.01, minDistance=10)
    if corners is not None:
        for c in corners:
            x, y = c.ravel()
            print("corner at (%.0f, %.0f)" % (x, y))

    # Template matching
    template = gray[97:103, 97:103].copy()
    result = cv2.matchTemplate(gray, template, cv2.TM_CCOEFF_NORMED)
    _, max_val, _, max_loc = cv2.minMaxLoc(result)
    print("best match at", max_loc, "score", max_val)

14) PITFALLS & NOTES
--------------------------------------------------------------------------------

- OpenCV uses BGR by default. Convert to RGB for matplotlib/PIL display:
    cv2.cvtColor(img, cv2.COLOR_BGR2RGB)

- This build includes only core and imgproc modules. HighGUI, video I/O,
  DNN, etc. are disabled to keep the wheel small.

- All images are numpy arrays. dtype is usually uint8 (0-255).

- __init__.py uses ctypes.CDLL to load .so files in dependency order.
  If you see ImportError or undefined symbol, check that libopencv_core.so
  and libopencv_imgproc.so are in the cv2/ package directory.

- numpy must be installed first: `pip install numpy`

- Wheels are tagged cp312-cp312-linux_<ABI>. Install the correct ABI wheel.

- For camera access, you would need VideoCapture which requires a camera HAL.
  This is not available in most Android apps without custom permissions.

- Drawing functions modify the image in-place. Pass a copy if you need the
  original: `copy = img.copy()`
