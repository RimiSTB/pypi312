--------------------------------------------------------------------------------
1) WHAT IS DUCKDB?
--------------------------------------------------------------------------------

DuckDB is an in-process SQL database management system (OLAP).
It provides:
  - Full SQL support (CTEs, window functions, subqueries, JOINs)
  - In-memory or file-based database
  - Columnar execution (fast analytics)
  - Zero configuration (no server needed)
  - Pandas DataFrame integration (fetchdf)
  - Arrow support (fetch_arrow_table)
  - Complex types: ARRAY, STRUCT, MAP

DuckDB is self-contained; no external dependencies.

    import duckdb
    print(duckdb.__version__)          # 1.x

            id INTEGER,
            name VARCHAR,

            age INTEGER
        )

    con.execute("INSERT INTO users VALUES (1, 'Alice', 'alice@example.com', 30)")

    # insert many at once
    rows = [(i, "user_%d" % i, "user%d@example.com" % i, 20 + i) for i in range(100)]
    con.executemany("INSERT INTO users VALUES (?, ?, ?, ?)", rows)

    # select
    result = con.execute("SELECT * FROM users WHERE age > 25 ORDER BY age").fetchall()
    print(result)

5) FETCH METHODS
--------------------------------------------------------------------------------

    con = duckdb.connect(":memory:")
    con.execute("CREATE TABLE t(id INTEGER)")
    for i in range(10):
        con.execute("INSERT INTO t VALUES (?)", [i])

    # fetchall - list of tuples
    rows = con.execute("SELECT * FROM t ORDER BY id").fetchall()
    # [(0,), (1,), ... (9,)]

    # fetchone - single tuple
    row = con.execute("SELECT * FROM t WHERE id = 0").fetchone()
    # (0,)

    # fetchmany - batch of N rows
    cur = con.execute("SELECT * FROM t ORDER BY id")
    batch = cur.fetchmany(5)   # first 5 rows

    # fetchdf - pandas DataFrame
    df = con.execute("SELECT * FROM t ORDER BY id").fetchdf()
    print(df.columns)   # ['id']

    # fetch_arrow_table - PyArrow Table
    at = con.execute("SELECT * FROM t").fetch_arrow_table()

6) PARAMETERIZED QUERIES
--------------------------------------------------------------------------------

    con = duckdb.connect(":memory:")
    con.execute("CREATE TABLE t(id INTEGER, name VARCHAR)")

    # safe parameterized query (prevents SQL injection)
    con.execute("INSERT INTO t VALUES (?, ?)", [1, "alice"])
    con.execute("INSERT INTO t VALUES (?, ?)", [2, "bob"])

    result = con.execute("SELECT * FROM t WHERE id = ?", [1]).fetchall()
    assert result == [(1, "alice")]

7) JOINS
--------------------------------------------------------------------------------

    con = duckdb.connect(":memory:")
    con.execute("CREATE TABLE a(id INTEGER, name VARCHAR)")
    con.execute("CREATE TABLE b(id INTEGER, score DOUBLE)")
    con.execute("INSERT INTO a VALUES (1, 'alice'), (2, 'bob')")
    con.execute("INSERT INTO b VALUES (1, 95.0), (2, 87.0)")

    # INNER JOIN
    result = con.execute("""
        SELECT a.name, b.score
        FROM a INNER JOIN b ON a.id = b.id
        ORDER BY a.name
    """).fetchall()
    # [('alice', 95.0), ('bob', 87.0)]

    # LEFT JOIN
    result = con.execute("""
        SELECT a.name, b.score
        FROM a LEFT JOIN b ON a.id = b.id
    """).fetchall()

8) AGGREGATES / GROUP BY
--------------------------------------------------------------------------------

    con = duckdb.connect(":memory:")
    con.execute("CREATE TABLE sales(product VARCHAR, amount DOUBLE)")
    for product, amount in [("A", 100), ("A", 200), ("B", 150), ("B", 300)]:
        con.execute("INSERT INTO sales VALUES (?, ?)", [product, amount])

    result = con.execute("""
        SELECT product, SUM(amount) as total, COUNT(*) as cnt
        FROM sales
        GROUP BY product
        ORDER BY product
    """).fetchall()
    # [('A', 300.0, 2), ('B', 450.0, 2)]

10) VIEWS / SUBQUERIES

    con = duckdb.connect(":memory:")
    con.execute("CREATE TABLE t(id INTEGER, name VARCHAR)")
    con.execute("INSERT INTO t VALUES (1, 'alice'), (2, 'bob')")

    # view
    con.execute("CREATE VIEW v AS SELECT * FROM t WHERE id = 1")
    result = con.execute("SELECT * FROM v").fetchall()
    assert result == [(1, "alice")]

    # subquery
    result = con.execute("""
        SELECT * FROM t
        WHERE id IN (SELECT id FROM t WHERE id = 1)
    """).fetchall()

15) ANDROID NOTES
--------------------------------------------------------------------------------

- DuckDB is self-contained; no external dependencies needed.
- The C++ build produces a single .so extension (pybind11-based).
- In-memory databases are fast; file databases persist across sessions.
- DuckDB is OLAP-optimized; for OLTP (many small writes), consider SQLite.
- fetchdf() requires pandas; fetch_arrow_table() requires pyarrow.
- Thread-safe for read operations; use separate connections for writes.
- Zero configuration: no server, no setup, just connect and query.
