--------------------------------------------------------------------------------
1) WHAT IS LIGHTGBM?
--------------------------------------------------------------------------------

LightGBM is a fast, distributed, high-performance gradient boosting framework.
It provides:
  - Gradient boosting decision trees (GBDT)
  - Binary classification, multi-class, regression, ranking
  - Leaf-wise (best-first) growth for high accuracy
  - Histogram-based algorithm for speed
  - GPU training support (not in this Android build)

Typical use: train a model to predict a target from features.

    import lightgbm as lgb
    print(lgb.__version__)          # 4.7.0

Custom evaluation:
    def custom_metric(preds, ds):
        labels = ds.get_label()
        preds_bin = (preds > 0.5).astype(int)
        acc = (preds_bin == labels).mean()
        return "custom_acc", acc, True   # higher_is_better = True

    bst = lgb.train(params, ds, num_boost_round=10,
                     valid_sets=[ds],

--------------------------------------------------------------------------------
10) PITFALLS & NOTES
--------------------------------------------------------------------------------

- lightgbm requires scipy and narwhals at runtime. Install them first:
    pip install scipy narwhals
- Binary classification uses log-loss by default. Use `pred > 0.5` for labels.
- Multi-class returns shape (n_samples, n_classes) - use argmax for labels.
- save_model uses a text format (.txt). This is lightgbm's native format.
- This Android build has GPU disabled. Use CPU-only training.
- num_threads=1 is recommended for Android (single process on device).
- Wheels are tagged cp312-cp312-linux_<ABI>. Install the correct ABI wheel.
- The lib_lightgbm.so is loaded via ctypes at runtime; if import fails,
  check that the .so is in the lightgbm package directory.
