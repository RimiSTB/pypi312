  1. OVERVIEW
================================================================================

zstandard provides Python bindings for the Zstandard (zstd) fast lossless
compression algorithm. This implementation wraps zstd via a single C file,
making it lightweight and easy to build for Android STB environments.

    python -m pip install --no-build-isolation zstandard

================================================================================
  4. USAGE EXAMPLE
================================================================================

    import zstandard as zstd

    data = b"Hello, Zstandard compression on Android!"
    compressor = zstd.ZstdCompressor()
    compressed = compressor.compress(data)
    decompressor = zstd.ZstdDecompressor()
    decompressed = decompressor.decompress(compressed)
    assert decompressed == data
