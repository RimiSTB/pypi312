================================================================================
  1. OVERVIEW
================================================================================

cchardet is a fast C++ character encoding detection library. It uses the
bundled uchardet library to automatically detect the character encoding
of a given byte sequence. It is significantly faster than the pure Python
charset-normalizer alternative.
