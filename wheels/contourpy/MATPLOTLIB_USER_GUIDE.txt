--------------------------------------------------------------------------------
1) WHAT IS MATPLOTLIB?
--------------------------------------------------------------------------------

matplotlib is the most widely used plotting library in Python. It provides:
  - Line plots, scatter plots, bar charts, histograms
  - Image display (imshow)
  - Contour plots, surface plots
  - Polar plots
  - Publication-quality figures (PNG, SVG, PDF, JPG)

This Android build uses the "Agg" backend (Anti-Grain Geometry) which renders
to files in memory -- no display/GUI needed.

    import matplotlib
    matplotlib.use("Agg")
    print(matplotlib.__version__)

--------------------------------------------------------------------------------
3) SETTING THE BACKEND
--------------------------------------------------------------------------------

ALWAYS set the backend before importing pyplot on a headless device:

    import matplotlib
    matplotlib.use("Agg")
    import matplotlib.pyplot as plt

If you forget `matplotlib.use("Agg")`, matplotlib may try to open a display
window and fail. Set it as the very first matplotlib import.

    fig.savefig(buf, format="png")
    data = buf.getvalue()

IMPORTANT: Always call plt.close(fig) after saving to free memory.

12) CONTOUR PLOTS
--------------------------------------------------------------------------------

    import numpy as np
    import matplotlib
    matplotlib.use("Agg")
    import matplotlib.pyplot as plt

    x = np.linspace(-2, 2, 50)
    y = np.linspace(-2, 2, 50)
    xx, yy = np.meshgrid(x, y)
    zz = np.sin(xx) * np.cos(yy)

    fig, ax = plt.subplots()
    cs = ax.contour(xx, yy, zz, levels=10)
    ax.clabel(cs, inline=True, fontsize=8)
    fig.savefig("contour.png")
    plt.close(fig)

13) POLAR PLOTS

    import matplotlib
    matplotlib.use("Agg")
    import matplotlib.pyplot as plt
    import numpy as np

    theta = np.linspace(0, 2 * np.pi, 100)
    r = 1 + 0.5 * np.cos(5 * theta)

    fig, ax = plt.subplots(subplot_kw={"projection": "polar"})
    ax.plot(theta, r)
    fig.savefig("polar.png")
    plt.close(fig)

--------------------------------------------------------------------------------
15) PITFALLS & NOTES
--------------------------------------------------------------------------------

- MUST set `matplotlib.use("Agg")` before importing pyplot. No GUI on Android.
- Always call `plt.close(fig)` to free memory after saving.
- This build includes 6 C extensions: ft2font, _path, _contour, _image,
  _tri, _qhull. They are compiled with Cython + meson.
- Dependencies: numpy, pillow, contourpy, kiwisolver, packaging, pyparsing,
  fonttools, cycler. All must be installed.
- Fonts: matplotlib ships its own fonts (DejaVu). No system fonts needed.
  If you need custom fonts, use matplotlib.font_manager.FontProperties.
- For large figures, increase DPI carefully: dpi=300 on a 10x10 figure
  creates a 3000x3000 pixel image (~27MB as PNG).
- Wheels are tagged cp312-cp312-linux_<ABI>. Install the correct ABI wheel.
- The Agg backend renders to file only. You cannot show() interactive windows.
