--------------------------------------------------------------------------------
1) WHAT IS PYDANTIC_CORE?
--------------------------------------------------------------------------------

pydantic_core is the Rust/PyO3 core of pydantic v2. It provides:
  - Fast JSON Schema validation
  - Type coercion and serialization
  - Rust-powered performance (10-50x faster than pydantic v1)

pydantic itself provides the Python API. pydantic_core does the heavy lifting.

    import pydantic
    print(pydantic.__version__)    # 2.12.5

    from pydantic import BaseModel
    class User(BaseModel):
        name: str
        age: int
    u = User(name="Alice", age=30)
    print(u.model_dump())          # {'name': 'Alice', 'age': 30}

4) VALIDATION

    from pydantic import BaseModel, ValidationError

    class User(BaseModel):
        name: str
        age: int

    # Valid
    u = User(name="Alice", age=30)

    # Invalid — raises ValidationError
    try:
        User(name="Alice", age="thirty")
    except ValidationError as e:
        print(e.errors())
        # [{'type': 'int_parsing', 'loc': ('age',), 'input': 'thirty', ...}]
        print(e.error_count())   # 1

    # From dict
    u = User.model_validate({"name": "Bob", "age": 25})

    # From JSON string
    u = User.model_validate_json('{"name": "Charlie", "age": 35}')

    from pydantic import BaseModel

    class Address(BaseModel):
        street: str
        city: str
        zip_code: str = ""

    class Person(BaseModel):
        name: str
        age: int
        address: Address

    # Create nested
    p = Person(
        name="Alice",
        age=30,
        address=Address(street="123 Main St", city="NYC")
    )

    # Access nested fields
    print(p.address.city)   # "NYC"

    # Dump to dict (recursive)
    print(p.model_dump())
    # {'name': 'Alice', 'age': 30, 'address': {'street': '123 Main St', 'city': 'NYC', 'zip_code': ''}}

9) TYPEADAPTER (STANDALONE VALIDATION)
--------------------------------------------------------------------------------

    from pydantic import TypeAdapter

    # Validate a single value
    ta_int = TypeAdapter(int)
    result = ta_int.validate_python("42")
    print(result)      # 42

    # Validate a list
    ta_list = TypeAdapter(list[int])
    result = ta_list.validate_python([1, 2, 3])
    print(result)      # [1, 2, 3]

    # Validate a dict with specific schema
    ta_dict = TypeAdapter(dict[str, int])
    result = ta_dict.validate_python({"a": 1, "b": 2})
    print(result)      # {'a': 1, 'b': 2}

--------------------------------------------------------------------------------
12) PITFALLS & NOTES
--------------------------------------------------------------------------------

- pydantic_core is a Rust extension. It provides the validation engine.
  You use it through the pydantic Python package.
- pydantic v2 is NOT backward-compatible with v1. The API is different.
- model_dump() returns a dict. model_dump_json() returns a JSON string.
- model_validate() takes a dict. model_validate_json() takes a JSON string.
- ValidationError contains detailed error information per field.
- Type coercion: pydantic coerces compatible types (e.g. "42" -> 42 for int).
  Use strict=True in Field() to disable coercion.
- Wheels are tagged cp312-cp312-android_24.
- Ships with pydantic 2.12.5, typing_extensions, annotated_types.
- No external runtime dependencies beyond the bundled packages.
- pydantic_core.core_schema provides the low-level schema API (advanced use).
