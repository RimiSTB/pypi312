================================================================================
  1. OVERVIEW
================================================================================

MarkupSafe is a library for making strings safe for HTML/XML output.
It provides a Markup type that automatically escapes variables and
supports string concatenation. The C extension provides significant
performance improvements over pure Python.

================================================================================
  4. USAGE EXAMPLE
================================================================================

    from markupsafe import Markup, escape

    safe = escape("<script>alert('xss')</script>")
    print(safe)  # &lt;script&gt;alert(&#39;xss&#39;)&lt;/script&gt;

    markup = Markup("<em>%s</em>") % "Hello"
