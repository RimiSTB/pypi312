WHAT IS CFFI?
-------------
CFFI (C Foreign Function Interface for Python) lets you call C functions and
use C data types from Python. It's the bridge between Python and native code.

In PythonSTB, cffi is used by:
  - cryptography (OpenSSL bindings)
  - pynacl (libsodium bindings)
  - argon2-cffi-bindings (password hashing)
  - pycares (c-ares DNS resolver)
  - Any package that wraps C libraries

QUICK START
-----------
from cffi import FFI

ffi = FFI()

# Define C functions to call
ffi.cdef("""
    int abs(int);
    long time(long *t);
""")

# Load a shared library
libc = ffi.dlopen(None)  # libc (default)
print(libc.abs(-42))     # 42

# Define C structs
ffi.cdef("""
    struct point {
        int x;
        int y;
    };
""")
p = ffi.new("struct point *", {"x": 10, "y": 20})

COMMON PATTERNS
---------------
# 1. Call libc functions
ffi.cdef("int abs(int);")
libc = ffi.dlopen(None)
result = libc.abs(-5)

# 2. Use C structs
ffi.cdef("struct tm { int tm_sec; int tm_min; int tm_hour; };")
tm = ffi.new("struct tm *")

# 3. Pass strings to C
ffi.cdef("size_t strlen(const char *);")
libc = ffi.dlopen(None)
s = ffi.new("char[]", b"hello")
print(libc.strlen(s))  # 5

# 4. Callback functions
ffi.cdef("int compare(const void *a, const void *b);")
@ffi.callback("int(const void *, const void *)")
def my_compare(a, b):
    return ffi.cast("int", a) - ffi.cast("int", b)

# 5. Inline C code (ABI mode)
ffi.cdef("int my_func(int x);", override=True)
ffi.set_source("_my_module", """
    int my_func(int x) { return x * 2; }
""")

ABI vs API MODE
---------------
ABI mode (simpler, no compilation):
  ffi.cdef("int abs(int);")
  libc = ffi.dlopen(None)
  # Works at runtime, no .so generation needed

API mode (more efficient, requires compilation):
  ffi.set_source("_mymod", "...")
  ffi.compile()
  # Generates a Python extension module

On Android, ABI mode is recommended — no compilation at runtime.

ANDROID NOTES
-------------
- cffi is built with norelro + 16KB page alignment
- Links against app's libffi.so at runtime
- pycparser is bundled in the Full_Wheel
- ABI mode works without compilation
- API mode (set_source/compile) requires a C compiler at runtime (not available)
