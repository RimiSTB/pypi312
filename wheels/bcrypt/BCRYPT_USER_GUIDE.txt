--------------------------------------------------------------------------------
1) WHAT IS BCRYPT?
--------------------------------------------------------------------------------

bcrypt is a password hashing library based on the Blowfish cipher.
It provides:
  - Password hashing with adaptive cost (rounds)
  - Salt generation with automatic random salts
  - Password verification against stored hashes
  - Key derivation function (kdf) for encryption keys
  - Built-in protection against timing attacks

bcrypt is self-contained (Rust/PyO3 build), no external dependencies.

    import bcrypt
    print(bcrypt.__version__)          # 4.x

--------------------------------------------------------------------------------
3) PASSWORD HASHING
--------------------------------------------------------------------------------

    import bcrypt

    # hash a password (generates random salt automatically)
    password = b"super secret password"
    hashed = bcrypt.hashpw(password, bcrypt.gensalt())
    print(hashed)     # b'$2b$12$...' (29 bytes + salt)

    # with custom rounds (default 12, min 4, max 31)
    hashed = bcrypt.hashpw(password, bcrypt.gensalt(rounds=10))

    # verify a password
    if bcrypt.checkpw(password, hashed):
        print("password matches!")
    else:
        print("wrong password!")

4) SALT GENERATION
--------------------------------------------------------------------------------

    import bcrypt

    # default salt (12 rounds)
    salt = bcrypt.gensalt()             # b'$2b$12$...'

    # custom rounds
    salt = bcrypt.gensalt(rounds=10)    # faster but less secure

    # salt is always 29 bytes
    assert len(salt) == 29

    # salt always starts with the bcrypt prefix
    assert salt[:3] in (b"$2a", b"$2b", b"$2y")

5) KEY DERIVATION (kdf)
--------------------------------------------------------------------------------

    import bcrypt

    # derive a 32-byte key (e.g. for AES-256)
    key = bcrypt.kdf(
        password=b"password",
        salt=b"salt" * 4,
        desired_key_bytes=32,
        rounds=1000,
    )
    assert len(key) == 32

    # derive a 64-byte key
    key = bcrypt.kdf(
        password=b"pass",
        salt=b"salt" * 2,
        desired_key_bytes=64,
        rounds=500,
    )
    assert len(key) == 64


--------------------------------------------------------------------------------
6) SECURITY BEST PRACTICES
--------------------------------------------------------------------------------

  - Always use bcrypt.gensalt() - never create your own salt
  - Default rounds=12 is good for most use cases
  - Higher rounds = slower = more secure against brute force
  - bcrypt truncates passwords at 72 bytes (by design)
  - Store the full hash (includes salt) in your database
  - Compare hashes with checkpw(), not string comparison
  - Use constant-time comparison (bcrypt handles this internally)

        save_to_db(username, hashed)

--------------------------------------------------------------------------------
8) ANDROID NOTES
--------------------------------------------------------------------------------

- bcrypt is self-contained; no external dependencies needed.
- The Rust/PyO3 build produces a single .so extension.
- For Android, use ABI-tagged wheels (android_24_arm64_v8a or x86_64).
- bcrypt works fully offline (no network needed).
- Thread-safe: can be used from multiple threads.
- Hashing is CPU-intensive by design; expect ~100ms per hash with rounds=12.
